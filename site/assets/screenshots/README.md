# Reflex website screenshot assets

Place cleaned app screenshots in this folder with the exact filenames below:

- dashboard-overview.png
- menubar-overloaded.png
- menubar-elevated.png
- insights-view.png
- history-view.png
- settings-view.png

Recommended export guidance:
- Prefer PNG for UI clarity, WebP if quality remains crisp.
- Keep long edge around 1600px to balance sharpness and payload.
- Preserve app window shadows if available.
- Use consistent cropping and corner radii.
